# 📱 uniOPOS PuenteWeb v2.0 (Comanda Móvil)
Sistema puente portátil para uniCenta oPOS 5.0.1 sobre MariaDB (24 mesas, productos auxiliares y sincronización automática).
Enlace de descarga directa y comando PowerShell express disponibles en el repositorio.
## 🚀 Guía de Instalación y Mantenimiento
Ejecuta `uniOPOS_Installer.bat` para la instalación en `C:\uniOPOS_PuenteWeb` o utiliza los comandos Git para actualizar el repositorio con la documentación de la versión `v2.0.0`.

# uniOPOS PuenteWeb v2.0 (Colombia)

Sistema puente autocontenido para conectar dispositivos móviles con **uniCenta oPOS 5.0.1** y **MariaDB** vía Wi-Fi local.

[![Descargar para Windows](https://shields.io)](https://github.com)

## Guía de Instalación Rápida
1. Haz clic en el botón verde **Descargar para Windows** para obtener `uniOPOS_Installer.bat`.
2. Ejecuta **`uniOPOS_Installer.bat`** como Administrador y presiona **`1`** y **Enter** en el menú interactivo.
3. El sistema configurará automáticamente Node.js, Java, MariaDB, Firewall y los accesos directos.

*(Para más detalles técnicos de mantenimiento, comandos de limpieza y estructura del paquete, consulta el repositorio oficial).*
